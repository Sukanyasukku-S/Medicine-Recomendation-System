Medicine Recommendation System

A Machine Learning based healthcare application that predicts possible diseases from user symptoms and provides detailed recommendations including medications, precautions, diet plans, workout suggestions, and chatbot-based assistance.

The system is designed to help users understand possible health conditions by analyzing symptoms entered in natural language and presenting personalized recommendations through an interactive web interface.

Features

• Disease prediction using Machine Learning

• Symptom normalization and preprocessing

• Detailed disease description

• Medication recommendations

• Diet recommendations

• Precautionary measures

• Workout and lifestyle suggestions

• Interactive healthcare chatbot

• Voice-enabled chatbot responses

• Modern healthcare dashboard UI

• Top disease prediction based on symptom analysis

How the System Works

1. User enters symptoms.

2. Symptoms are normalized using NLP preprocessing.

3. The trained Machine Learning model predicts the most relevant disease.

4. Disease details are retrieved from the dataset.

5. Recommendations such as medication, diet, precautions, and workout plans are displayed.

6. The chatbot explains the prediction.

7. Voice assistant reads the prediction and recommendations.

Installation and Execution

Step 1: Clone Repository

git clone <repository-url>

Step 2: Navigate to Project

cd Medicine-Recommendation-System

Step 3: Install Required Packages

cd backend

pip install -r requirements.txt

Step 4: Train the Model

python train_model.py

Model files will be generated inside the model folder.

Step 5: Start Backend Server

python app.py

Backend will run on:

http://127.0.0.1:5000

Step 6: Open Frontend

Navigate to the frontend folder and open:

index.html

in your browser.

Step 7: Test the Application

Enter symptoms such as:

cold, cough, sneezing, sore throat

Click Predict.

The system will display:

• Predicted Disease

• Description

• Precautions

• Medication Guidance

• Diet Recommendations

• Workout Suggestions

• Chatbot Explanation

• Voice Assistant Output
